# MFCC-Optimization-Work



## Overview

This repository contains the code used in the paper: 

《Optimizing MFCC parameters for the automatic detection of respiratory diseases》


## Contents

Jupyter notebooks with the main experiments (feature extraction, model build up).
The notebook shows an example for one dataset, the code for the other dataset follow the same pipeline and feature extraction, and model build up code.


## Citation
